# Imágenes de portfolio

Esta carpeta está reservada para capturas de Swagger UI, ejecución de tests, flujo de incidentes o una demostración desplegada.

Antes de publicar una captura:

- oculte tokens JWT, correos reales, contraseñas y secretos;
- no muestre el contenido de `.env`;
- use datos ficticios;
- compruebe que no aparezcan rutas o identificadores sensibles del equipo local.
